Snapshots

One dated folder per run, each a complete copy you can browse or restore from. Unchanged files are hard links to the previous snapshot, so only what changed takes new space. A snapshot no tier is holding is deleted by the next run.

Shared ignore rules

These apply to every machine. One glob per line; blank lines and # comments are skipped.

Saving is retroactive: anything already here that a rule now excludes is taken out of the index and moved to the trash, and every machine stops listing it. The copies on those machines are left alone — the rule means "stop syncing this", not "delete it".
